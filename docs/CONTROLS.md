## 键盘与触屏 / Keyboard and touch

| 动作 / Action | Keyboard | 手机 / Touch |
| --- | --- | --- |
| 移动、转向 / Move, turn | A / D（← / → 也可） | 左摇杆左右 / Stick left or right |
| 蹲伏 / Crouch | S / ↓ | 摇杆下拉，蹲防 / Pull down to crouch-guard |
| 站立防御 / Standing guard | F | 触屏主要使用蹲防与闪避 / Touch offers crouch-guard and Dodge |
| 普攻 / Attack | J | 普攻 / Attack |
| 重击 / Heavy | H | 重击 / Heavy |
| 跳跃 / Jump | K / ↑ | 跳跃 / Jump |
| 闪避 / Dodge | L / Shift | 闪避 / Dodge |
| 远程 / Ranged | U | 远程 / Ranged |
| 小技 / Minor | O | 小技 / Minor |
| 特殊技 / Special | E | 特殊技 / Special |
| 必杀 / Super | I | 必杀 / Super |
| 升龙 / Launcher | W + J | 摇杆↑＋普攻 / Stick up + Attack |
| 菜单 / Menu | Esc | 菜单按钮 / Menu button |
| 训练重置 / Reset training | R | 右上角「重置」/ Reset at top right |

W 是升龙组合方向；键盘的 ↑ 或 K 才是独立跳跃。闪避可穿过对方，穿身后需要自己转向。必杀需要 70 能量。

W supplies the launcher direction; Arrow Up or K jumps independently. Dodge can pass through an opponent; turn manually afterward. Super requires 70 energy.

## 先练这三套 / Three routes to learn

| 连招 / Route | Keyboard | Touch |
| --- | --- | --- |
| 三段起手 / Three-hit starter | J → J → J | 普攻 → 普攻 → 普攻 / Attack ×3 |
| 升龙追击 / Launcher follow-up | W+J → K → J → J → H | 摇杆↑＋普攻 → 跳跃 → 普攻 → 普攻 → 重击 / Stick up + Attack → Jump → Attack → Attack → Heavy |
| 空中爆发 / Air burst | K → J → J → E → I | 跳跃 → 普攻 → 普攻 → 特殊技 → 必杀 / Jump → Attack → Attack → Special → Super |

**命中后再衔接。** 训练场检查真正的命中顺序，距离不够、能量不足、按得过早或对手已恢复行动，都可能不计为完成。右上角同时显示完整路线、当前进度与下一步；用「换连招」切换练习。训练设置可改变木桩行为、距离、空中阶段、资源和命中框。

**Confirm each hit before following up.** Training checks real hit sequences. Being out of range, lacking energy, pressing too early or letting the opponent recover can break the route. The top-right coach shows the whole sequence, progress and next move. Change combo to practise another route; training settings control the dummy, distance, airborne phase, resources and hitboxes.

## 手机上屏幕怎么摆 / Mobile layout

**横屏：** 左边只有摇杆；右边为普攻、重击、跳跃、闪避和技能。准备倒计时可以提前熟悉触控，角色在开战前不会受操作影响；保持摇杆方向，开战后即可接着移动。

**Landscape:** only the stick is on the left; all actions are on the right. During the ready countdown, controls respond visually without moving the fighter. Held movement continues when combat begins.

**竖屏：** 上方显示战斗，下方模拟掌机机壳，将常用动作分成更大的独立按钮。横屏是建议，不是强制要求。

**Portrait:** the battle occupies the upper area, with a handheld-style shell and larger separate buttons below. Landscape is recommended, not compulsory.

## 添加到主屏幕 / Add to the home screen

iPhone：在 Safari 打开当前游戏网页 → 分享 → 添加到主屏幕 → 若系统提供「作为网页 App 打开」，将其开启 → 添加。之后点主屏幕游戏图标进入。想横屏时解除系统竖排方向锁定，再横置手机。不同系统版本的按钮位置可能不同。[Apple 官方说明](https://support.apple.com/guide/iphone/iphea86e5236/ios)

iPhone: open the current game page in Safari → Share → Add to Home Screen → enable Open as Web App if offered → Add. Launch the game icon from the home screen. Turn off Portrait Orientation Lock before rotating. Button locations vary by OS version. [Apple instructions](https://support.apple.com/guide/iphone/iphea86e5236/ios)

Android：在 Chrome 打开当前游戏 → 右上角 ⋮ → 添加到主屏幕／安装；按浏览器显示的选项完成，再从主屏幕打开。系统自动旋转需要开启。部分浏览器只会创建快捷方式，游戏会根据实际环境提示。[Chrome 官方说明](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid)

Android: open the current page in Chrome → ⋮ → Add to Home Screen / Install, then follow the browser's options. Enable system auto-rotate. Some browsers create a shortcut rather than a standalone web app; the game checks the actual environment. [Chrome instructions](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid)

普通浏览器也可在了解误操作风险后继续。游戏抑制战斗区域的文字选中及常见缩放手势；操作系统手势仍由系统控制。网页 App 不等于离线安装包，加载资源、联机及钱包操作仍需要网络。

Regular browser play is also available after acknowledging accidental-gesture risks. The game suppresses text selection and common zoom gestures in combat; OS gestures remain system-controlled. A home-screen web app is not an offline installer: loading, multiplayer and wallet operations still require connectivity.

## 钱包返回与声音 / Wallet return and audio

- 手机首次登录包含「连接钱包」和「登录签名」两个确认，二者不等于支付。回到原来的游戏窗口或主屏幕 App，按当前步骤继续，不必重复建房。若系统没有再次拉起 OKX，使用对话框中的打开／继续按钮。[钱包详解](X-LAYER.md)
- 浏览器通常需要一次点击才能开始播放音乐。点击首页「开启音乐」或在菜单的声音设置中开启，并检查手机静音、媒体音量和蓝牙输出。
- 单人模式打开菜单会暂停；联机比赛不会因为你打开菜单而暂停。

Mobile login has two distinct confirmations: wallet connection and a login signature, neither a payment. Return to the original game window or home-screen app and continue the current step. Use the dialog's Open/Continue control if OKX does not reopen. [Wallet guide](X-LAYER.md)

Browsers normally require a user gesture before playing sound. Select Enable music in the lobby or enable it in the menu's audio settings, then check mute, media volume and Bluetooth output. Solo menus pause play; online matches continue while a menu is open.
